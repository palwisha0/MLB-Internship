 1. Data Cleaning Steps
 I checked for empty values and filled them.
 I fixed wrong and negative marks.
 I removed duplicate students.
 I made all subject names same.
 I saved the clean data as cleaned_student_performance.csv
 2. Visualizations I Created and Why
 Bar Chart: To show average marks of each subject.
 Histogram: To see how marks are distributed.
 Pie Chart: To show pass and fail students.
 Scatter Plot: To see relation between Math and Python marks.
 Box Plot: To see marks difference in each subject.
 3. Three Key Insights
 1. Python has the highest average. Students are good in Python.
 2. Machine Learning has the lowest average. It is the hardest subject.
 3. Some students have marks below 40. They need more help and improvement.
